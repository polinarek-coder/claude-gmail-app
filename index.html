Claude Gmail

Prywatne narzędzie do obsługi własnych skrzynek Gmail właściciela przez asystenta Claude Code. Aplikacja nie jest udostępniana innym użytkownikom.

Polityka prywatności

Aplikacja korzysta z Gmail API wyłącznie na kontach należących do właściciela. Dane z Gmaila są przetwarzane lokalnie na urządzeniach właściciela, nie są sprzedawane, udostępniane ani przekazywane osobom trzecim i nie są używane do reklam. Tokeny dostępu są przechowywane tylko na urządzeniach właściciela i można je w każdej chwili cofnąć na stronie myaccount.google.com/permissions.

Wykorzystanie danych otrzymanych z interfejsów API Google jest zgodne z zasadami dotyczącymi danych użytkownika w usługach interfejsu API Google, w tym z wymaganiami dotyczącymi ograniczonego użytku.
